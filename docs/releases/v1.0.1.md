# 芝码 v1.0.1

芝码是从 my-Auth 逐步改造而来的本地 TOTP 验证器。“芝麻开门，验证码就绪。”这一版统一了应用名称、桌面图标和启动画面，并整理了新版 Android 的使用与迁移说明。

## 功能

- 相机扫码与 Android 系统选图识别验证二维码。
- SHA-1 / SHA-256 / SHA-512，6 / 8 位验证码，30 / 60 秒周期。
- 点击复制、搜索、置顶、修改显示名称与删除确认。
- 密码加密备份、恢复前解密预览与重复项保留现有账户。
- 暖白、雾紫、浅绿背景，统一弹窗与等待反馈。
- 全新“芝码”图标与启动画面；修复此前 Auth 1.0.0 安装包的空白桌面图标。

## 安装与迁移

附件：`Zhima-1.0.1-20261027.apk`，大小 **15,473,895 字节**（约 14.8 MiB）。

- 应用名：芝码；版本：1.0.1（101）。
- 包名：`io.github.snowcgj.myauth`。
- 已安装本次 Auth 1.0.0 的用户可直接覆盖安装，包名及签名保持一致；不要先卸载，以免丢失应用内账户。
- 2024 年旧版 `uni.UNI1835605` 与本版可以分别安装，账户不会自动迁移。旧版没有导出能力时，可在对应网站的安全设置中更换验证器并重新扫码绑定；新验证器成功登录后再处理旧记录。
- 安装、迁移完成后，创建加密备份，在手机之外保留副本并妥善保存密码。

## 验证与范围

实际 APK 已核对应用名、版本与包名，签名校验通过且与上一云包一致；从最终 APK 提取的四密度图标均含完整图案。维护者已反馈新版安装使用正常，并完成 GitHub 验证器迁移及备份相关收尾。这些反馈不代表所有机型或全部 Android 版本均已覆盖。

验证码核心、解析、备份与账户逻辑有自动测试；原生桥接的模拟测试不能替代真机测试。H5、微信小程序和 iOS 本版不作可用性承诺。

## 数据保护与限制

- 验证码本地计算，不提供账户云同步或芝码账号服务。
- 备份文件使用密码加密并校验完整性，密码遗忘无法找回。
- **应用内账户存储尚未做应用层加密，也没有应用锁。**
- 当前不支持 HOTP、手动输入密钥或修改验证码参数。
- 本项目代码采用 MIT；第三方依赖与 DCloud Runtime 遵循各自条款。
