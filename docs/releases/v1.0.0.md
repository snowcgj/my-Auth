# Auth 1.0.0

> 本页是2026年重构阶段的 Auth 1.0.0 草稿，未据此创建 Release；仓库已有的 v1.0.0 Release 属于2024年旧版，不由本页描述。当前发行版见 [芝码 v1.0.1](v1.0.1.md)，不要沿用本页的待填写项或旧 APK。

本地 TOTP 验证器的新版 Android 应用，提供暖白界面与离线账户管理。

## 功能

- 扫描验证二维码，或从 Android 系统相册选择图片识别。
- SHA-1 / SHA-256 / SHA-512，6/8 位验证码，30/60 秒周期。
- 一键复制、搜索、置顶、修改显示名称与删除确认。
- 密码加密备份、解密预览与重复账户跳过恢复。
- 暖白、雾紫、浅绿背景，以及统一弹窗与等待反馈。

## 安装与迁移

- 包名：`io.github.snowcgj.myauth`；版本：`1.0.0`（100）。
- 本版使用新包名，可与旧版分别安装，账户不会自动从旧版搬入。
- 如旧版不支持当前备份格式，请通过网站提供的迁移或重新绑定流程添加账户；确认新版可用前保留旧版。不要假设任意验证器的导出格式都可导入。
- 当前只面向 Android；不承诺尚未测试的系统版本、图片格式或机型均可用。

## 数据与安全范围

- 验证码在本地生成，无需注册，不提供账户云同步。
- 导出备份使用密码加密，密码遗忘无法找回。
- 本地账户存储尚未做应用层加密，也没有应用锁。
- 发布 APK 的最终权限以实际安装包核验结果为准，不能仅凭源码权限列表断言原生 Runtime 没有额外权限。
