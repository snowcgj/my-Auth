# 浅色背景偏好

日期：2026-10-27。基线：23d7a06。代码与本地验证完成，Android 真机待验。

## 为什么只切换浅色背景

当前暖白、淡紫和黑色按钮已获用户认可。本轮提供暖白、雾紫、浅绿三套背景，保留白卡片、紫色置顶、品牌图标和警示色，保证验证信息辨识度；不扩展为深色模式或图片壁纸。

## 应用与持久化

theme.js 提供唯一预设表和样式变量，三页在根 ui-page 绑定变量，页面内弹层自然继承；页面底色、输入框、边框、次按钮及弹层随预设变化。文字近似颜色适当归并到既有 muted。

使用独立 ui-theme 键存储白名单 ID。选色时保存成功才切换，失败保留原配色并提示重试；取消、遮罩和系统返回关闭选择器。各页初始化及 onShow 重新读取偏好，当前导航结构下无需全局订阅或新 store。读取失败/非法值回退暖白，不尝试自动修复存储。

不读写 accounts/backup_meta，不把设备外观偏好纳入账户备份。没有新依赖、权限、平台 API 或业务计时器。短屏选择面板允许滚动，遮罩单独阻止穿透手势，不阻止面板内滚动。

## 原生边界与验证

pages.json 与启动窗口仍为静态暖白；切页/回弹/启动短暂露底、Android CSS 变量继承、重启恢复及原生状态栏需真机确认。本轮不为该差异引入未经验证的原生背景 API。
