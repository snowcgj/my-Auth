# 系统选图与共用原生结果入口

- 用户希望相册使用 Android 原生界面，选择 Photo Picker（33+）与 ACTION_OPEN_DOCUMENT(image/*) 兼容路径，不用已废弃的 gallery.system，不新增插件/存储权限。
- 备份与选图共用一个主 Activity；分别覆盖 onActivityResult 会丢失另一方结果。因此将备份 2001/2002 和选图 3001 迁入一次安装的监听，保持一个 pending 选择器互斥，而非引入并行多选择器。
- 内容 URI 由 ContentResolver 读入私有缓存，不转为外部文件路径。纯 Java Channels/ByteBuffer 分块传输，避开本机已知 JS byte[] 桥接问题与逐字节大图开销；每次读写数字返回值与文件长度均检查。
- 图片内容不记日志；本次缓存文件在完成后删除，原图不动。复制仍在当前 JS 调用编排中进行，不宣称后台线程或所有图片格式支持；原生调用未返回时无法假装取消/删除仍在使用的文件。
- 保留相机入口；页面卸载令牌失效后不添加账户。非 Android 隐藏系统图片识别入口。
- 代码和模拟测试通过，用户已确认相册识别功能真机可用；其他机型/格式、异常、大图性能和备份交叉回归不超出用户反馈范围认定。验收与本地提交授权见 `.ai/plans/2026-10-27-system-image-scan.md`。
