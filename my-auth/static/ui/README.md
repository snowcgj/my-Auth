# 本地图形

本目录为 2026-10-27 视觉改版使用的离线资源，不调用在线图标或 favicon 服务。

- 通用图标：48 × 48 PNG，`-light` 为浅色版本。
- `image`/`image-light` 为系统选图入口新增的同风格图标，保留 SVG 源文件。
- 应用标识与服务标识：96 × 96 PNG。
- 空状态插画：480 × 440 PNG。
- 同名 SVG 为可编辑源文件；页面使用 PNG，避免不同运行端的 SVG 展示差异。

通用图标、应用标识与插画由本次原型中的矢量图形生成。GitHub、Wise、Microsoft 标识用于辨认对应服务，不代表官方关联或授权背书。其余服务使用服务名称首字符与稳定配色，不上传账户名称查询图标。
